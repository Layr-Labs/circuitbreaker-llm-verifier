# F. Elementary algebraic and arithmetic facts

This file proves the elementary facts used by `proof.md` and `disperser.md`.
Only the definitions of fields, polynomial rings and Lagrange's theorem for
finite groups are assumed.

## F1. Roots

Over any field, a nonzero polynomial of degree `D` has at most `D` roots
(division by `X - a` for each root `a`). In a commutative ring of
characteristic 2, `(a + b)^2 = a^2 + b^2`, and hence
`(a + b)^(2^s) = a^(2^s) + b^(2^s)` for all `s >= 0`.

## F2. Irreducible polynomials of prime degree over `F_2`

Fix a prime `k >= 2`. For a monic `q in F_2[z]` of degree `k`, the test
`T(q)` holds iff (i) `z^(2^k) = z (mod q)`, (ii) `q(0) = 1` and (iii)
`q(1) = 1`. `T(q)` is decidable in time polynomial in `k`: compute
`z^(2^k) mod q` by `k` successive squarings modulo `q`.

**F2.1.** If `g` is irreducible of degree `e` and `g` divides `z^(2^k) - z`,
then `e` divides `k`.
*Proof.* `L = F_2[z]/(g)` is a field with `2^e` elements; let `zeta` be the
class of `z`, so `zeta^(2^k) = zeta`. The map `phi(a) = a^2` is a ring
homomorphism of `L` (F1), injective since `L` is a field, hence bijective.
The set `{a : phi^k(a) = a}` is a subring containing `F_2` and `zeta`, hence
equals `L`, which is generated by `zeta`. By Lagrange in the group `L^*` of
order `2^e - 1`, also `phi^e(a) = a` for all `a`. Let `g0 = gcd(e, k)` and
write `g0 = u e - v k` with integers `u, v >= 0`. Then for every `a`,
`phi^(g0)(a) = phi^(g0)(phi^(vk)(a)) = phi^(ue)(a) = a`. So every element of
`L` is a root of `Y^(2^g0) - Y`, whence `2^e <= 2^g0` (F1) and `e = g0`
divides `k`. QED.

**F2.2.** `z^(2^k) - z` has no repeated irreducible factor. *Proof.* The
formal derivative `D(sum c_i z^i) = sum i c_i z^(i-1)` is linear and
satisfies `D(uv) = D(u)v + uD(v)` (check on monomials). If
`P = z^(2^k) - z = g^2 h`, then `D(P) = 2 g D(g) h + g^2 D(h)` is divisible by
`g`; but `D(P) = 2^k z^(2^k - 1) - 1 = 1` over `F_2`, impossible. QED.

**F2.3.** If `q` is monic of degree `k` and `T(q)` holds, then `q` is
irreducible. If `q` is irreducible of degree `k`, then `T(q)` holds.
*Proof.* Suppose `T(q)`. By (i), `q` divides `z^(2^k) - z`; so every
irreducible factor of `q` divides it, has degree 1 or `k` (F2.1, `k` prime),
and occurs once (F2.2). The only degree-1 polynomials are `z` and `z + 1`,
excluded by (ii) and (iii). So `q`, of degree `k`, is a single irreducible
factor. Conversely, if `q` is irreducible of degree `k >= 2`, it has no root
in `F_2`, giving (ii) and (iii); and `L = F_2[z]/(q)` is a field with `2^k`
elements, so by Lagrange `zeta^(2^k) = zeta` for the class `zeta` of `z`,
which is (i). QED.

**F2.4.** There exists a monic irreducible `q in F_2[z]` of degree `k`, and
hence (F2.3) one with `T(q)`.
*Proof.* `P = z^(2^k) - z` has degree `2^k`. Factor it into monic
irreducibles; by F2.1 each has degree 1 or `k`, and by F2.2 they are
distinct. The degree-1 factors are among `z`, `z+1`, of total degree at most
2. Since `2^k > 2`, some factor has degree `k`. QED.

## F3. The field `K`

Let `q` be monic irreducible of degree `k` (prime, `k >= 3`) and
`K = F_2[z]/(q)`, a field with `2^k` elements whose elements are written
uniquely as `sum_{j<k} c_j z^j` (polynomial basis). Then:

- `a^(2^k) = a` for all `a in K` (Lagrange in `K^*`, and `a = 0`), and
  `a^(2^k - 1) = 1` for `a != 0`.
- `sigma(a) = a^2` is an `F_2`-linear field automorphism of `K` (F1;
  injective, hence bijective).
- If `0 < s < k` and `a^(2^s) = a`, then `a in {0,1}`: as in F2.1, the
  fixed points of `sigma^s` and of `sigma^k = id` are fixed by
  `sigma^(gcd(s,k)) = sigma`, and the roots of `Y^2 - Y` are `0, 1`.
- `Tr(a) = sum_{j=0}^{k-1} a^(2^j)` satisfies `Tr(a)^2 = sum_{j=1}^{k}
  a^(2^j) = Tr(a)` (using `a^(2^k) = a`), so `Tr(a) in {0,1}`; `Tr` is
  `F_2`-linear by F1.
- Field operations on the coordinate vectors (`c_0,...,c_{k-1}`) take time
  polynomial in `k`; `a^e` for `e < 2^(k)` takes `O(k)` multiplications by
  repeated squaring; `Tr(a)` takes `k` squarings.

## F4. Primes in short intervals

**F4.** For every real `X >= 2^18` there is a prime in `(X, 8X]`.

*Proof.* Write `pi(y)` for the number of primes `<= y` and `ln` for the
natural logarithm.

(1) For every integer `n >= 1`, `prod_{p <= n} p <= 4^n`. Induction: true
for `n = 1, 2`; for even `n > 2` the product equals that for `n - 1`; for
`n = 2j + 1`, every prime `p in (j+1, 2j+1]` divides `binom(2j+1, j)`, which
is at most `4^j` because `binom(2j+1,j) = binom(2j+1,j+1)` and both occur in
`sum_i binom(2j+1,i) = 2^(2j+1)`; so the product is at most
`4^(j+1) * 4^j = 4^n`.

(2) For every integer `j >= 1`, `binom(2j, j) >= 4^j/(2j+1)` (it is the
largest of the `2j+1` terms of `sum_i binom(2j,i) = 4^j`). By Legendre's
formula (the exponent of `p` in `N!` is `sum_{a >= 1} floor(N/p^a)`, as
`floor(N/p^a)` counts multiples of `p^a` up to `N`), the exponent of `p` in
`binom(2j,j)` is `sum_{a>=1} (floor(2j/p^a) - 2 floor(j/p^a))`; each summand
is 0 or 1 and vanishes when `p^a > 2j`. So each prime-power factor of
`binom(2j,j)` is at most `2j`, only primes `p <= 2j` occur, and
`4^j/(2j+1) <= (2j)^(pi(2j))`, i.e. `pi(2j) >= (j ln 4 - ln(2j+1))/ln(2j)`.

(3) For real `X >= 4`, applying (1) with `n = floor(X)` to the primes in
`(sqrt X, X]`, each of which exceeds `sqrt X`, gives
`(sqrt X)^(pi(X) - pi(sqrt X)) <= 4^X`, so
`pi(X) <= sqrt X + 2 X ln 4 / ln X`.

(4) Let `X >= 2^18`, `j = floor(4X)` and `Y = 2j`, so `8X - 2 < Y <= 8X`
and `j >= 4X - 1`. Since `ln X >= 18 ln 2 >= 6 ln 8`, we have
`ln(8X) <= (7/6) ln X`; the numerator `(4X-1) ln 4 - ln(8X+1)` below is
positive, so by (2)

    pi(Y) >= ((4X - 1) ln 4 - ln(8X + 1)) / ln(8X)
          >= (24/7) X ln 4 / ln X - (6/7)(ln 4 + ln(8X+1)) / ln X.

Hence by (3)

    pi(Y) - pi(X) >= (10/7) X ln 4 / ln X - sqrt X - (6/7)(ln 4 + ln(8X+1))/ln X.

The function `sqrt(y)/ln(y)` is increasing for `y > e^2`, and at `y = 2^18`
it equals `512/(18 ln 2) > 41`; so `X / ln X >= 41 sqrt X`, and
`(10/7) X ln 4 / ln X >= (10/7)(1.38)(41) sqrt X > 80 sqrt X`. The last term
is below 2 because `ln 4 + ln(8X+1) <= 2 ln X` for `X >= 2^18`. Therefore
`pi(Y) - pi(X) > 79 sqrt X - 2 > 0`: some prime lies in `(X, Y]`, a subset of
`(X, 8X]`. QED.

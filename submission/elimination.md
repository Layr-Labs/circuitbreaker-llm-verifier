# Part E. Gate elimination: 3.5n - 7d for every affine disperser (complete re-derivation)

This file re-derives, in the pinned B2 model, the argument of O. S. Mishra and R. Santhanam, "An Explicit 3.5n − o(n) Size Lower Bound against General Boolean Circuits", ECCC TR26-260 (2026), Sections 2–4 (Theorem 4.1 there). All definitions and every case are written out; the paper is credited but nothing is used by citation. Facts used by name: Gaussian elimination and determinants over F_2 (elementary row operations, expansion along a column with a single nonzero entry, det(AB) = det A det B).

**Theorem E.** Let f : F_2^n -> F_2 be nonconstant on every affine subspace of F_2^n of dimension d, where 0 <= d < n. Then every circuit in the pinned B2 model computing f has at least 3.5 n - 7 d gates.

## E1. The pinned model and its embedding into states

A pinned circuit on inputs X_1..X_n is a finite directed acyclic graph whose vertices are input nodes (labelled by a variable X_i or by a constant 0/1) and gates; every gate has exactly two ordered input wires (both may come from the same vertex), is labelled by one of the 16 functions F_2^2 -> F_2, and computes that function of the values on its input wires. One vertex (a gate or an input node) is the output. Size |C| = number of gates, all 16 operations counted, including constant and unary ("degenerate") gates. Fan-out is unrestricted. Nothing else costs. Of the 16 operations: 2 are constant, 4 are unary (depend on exactly one input; they compute that input or its negation), 2 are **XOR-type** (t_1 + t_2 + c) and 8 are **AND-type** ((t_1 + a)(t_2 + b) + c), a, b, c in F_2. Every operation has a unique multilinear form c + b_1 t_1 + b_2 t_2 + b_{12} t_1 t_2; it is affine iff b_{12} = 0 (constant, unary and XOR-type operations).

Our proof manipulates generalized objects ("states") that include every pinned circuit as a special case, with the same size. Any gate reading a literal (negation) of a value is written as a gate with a modified operation; B2 is closed under negating inputs and output, so this is only notation. The output may be a constant, or a literal (t or t+1) of a parameter, auxiliary variable or gate. A pinned circuit whose output is a negation gate is still counted with that gate; it is simply a state in which a unary gate is present, and the argument deletes it (E3, D1) with a decrease of the potential. Thus the lower bound proved for states applies verbatim to pinned circuits. Cycles never arise in the gate part: all rewiring of linear parts happens inside an "affine system" of equations whose unique solvability is maintained explicitly (E2), which is how "cycles" are handled.

## E2. States

**Parameters and the map Phi.** A state carries an integer m >= 0 of parameters u = (u_1..u_m), a set P of pairwise disjoint 2-element subsets of the parameters ("pairs"; a parameter in a pair is *paired*, its mate is its *partner*; others are *unpaired*), and an injective map Phi : F_2^m -> F_2^n of the form
    Phi(u) = b + L u + sum_{{p,r} in P} c_{p,r} p r,            (1)
with b, c_{p,r} in F_2^n, L in F_2^{n x m}. q := |P|, a := m - q.

**Fair semi-circuit** on u: (i) an *affine system* of e >= 0 equations over F_2 in the parameters and in e further *auxiliary variables* v = (v_1..v_e): A v = N u + c with A in F_2^{e x e}, N in F_2^{e x m}, c in F_2^e, where every row of (A | N) has at most three nonzero entries, and A is invertible ("fairness"); (ii) an *acyclic part*: a list of gates in a topological order, each with an operation from the 16 and two inputs, each input a constant, a parameter, an auxiliary variable or an earlier gate; (iii) an output: a constant or a literal of a parameter, an auxiliary variable or a gate. Internal values := parameters, auxiliary variables, gates. Since A is invertible, every assignment to u extends uniquely to all internal values (v = A^{-1}(N u + c), then the gates in order); in particular each auxiliary variable is an affine function of u, v = A^{-1} N u + A^{-1} c. Size s := e + (number of gates). The *main invariant*: C(u) = f(Phi(u)) for all u in F_2^m.

**Initial state** for a pinned circuit C: m = n, Phi = identity, P empty, no equations, acyclic part = C (input nodes labelled X_i become the parameters u_i; constant input nodes are constants), output as in C. So s = |C|, a = m = n.

**Children, degree, weight, potential.** A gate is a *child* of each internal value it reads; an equation is a child of each internal value appearing in it with nonzero coefficient; a gate reading the same value twice counts once. deg(x) := number of distinct children of x. A parameter is *unused* if deg = 0 and *isolated* if deg = 1. (Degree is syntactic: it counts direct occurrences only.) For an unpaired parameter x, wt(x) := 0, 6, 7 according as deg(x) = 0, = 1, >= 2. Paired parameters have no weight. The potential is
    W := 2 s + 3 q + sum_{x unpaired} wt(x)  >= 0.
For a quantity X, Delta X := X' - X across a step (a step may group several operations).

**E2.1 (Proposition 2.2 of MS).** For every state, im Phi contains an affine subspace of dimension a = m - q. Hence if a >= d then f o Phi is nonconstant, i.e. the state's function C is nonconstant.
Proof. Choose one parameter from each pair and fix it to 0. The pairs are disjoint, so exactly q parameters are fixed, every quadratic term becomes affine, and the restricted map is an injective affine map from F_2^{m-q} into F_2^n; its image is an affine subspace of dimension a inside im Phi. f is nonconstant on it when a >= d (it contains a subspace of dimension d), so f o Phi is nonconstant.

**Changes of parameters.** Each of the following replaces Phi by Phi o tau for an injective tau expressing the old parameters by the new ones, so the new Phi is injective and of the form (1); the same change is made in the circuit, preserving the main invariant.
- (AR) affine reparametrisation: for an unpaired x and an affine map phi of the other parameters, x <- w + phi(u_{-x}) with w a fresh parameter (tau bijective; m, q, a unchanged; im Phi unchanged; x is unpaired so it occurs in (1) only linearly, hence the form (1) is kept).
- (QR) quadratic reparametrisation: for distinct unpaired x, y, z and constants al, be, ga: z <- w + (x + al)(y + be) + ga, and {x, y} is added to P (tau bijective; m unchanged, q + 1, a - 1; z unpaired so the new quadratic term c_{x,y} := L_z and no other quadratic term changes; x, y were unpaired so P stays a set of disjoint pairs).
- (UF) fixing an unpaired x: impose x = psi(u_{-x}) with psi affine; used only with psi a constant or psi = y + c for another parameter y. (m - 1, q unchanged, a - 1.)
- (PF) fixing a paired p with partner r: impose p = constant or p = r + c, and remove p and the pair {p, r} (so r becomes unpaired). (m - 1, q - 1, a unchanged.)
In (UF)/(PF) every occurrence of the fixed parameter in the circuit becomes a constant or a literal of another parameter; no gate is added and no equation gains a nonconstant term. (AR) and (QR) are implemented without substituting into the circuit (E3).

**Rerouting.** When a gate or auxiliary variable becomes a constant or a literal of another internal value, we replace every occurrence of it by that constant or literal ("reroute") and delete it. Rerouting to a literal of a parameter can increase that parameter's degree; rerouting to a constant increases no degree. Rerouting a gate changes no equation (no wires go from the acyclic part into the affine system).

**Preservation of the invariants (three terms per equation, A invertible).** Fixing a parameter x to a constant deletes the column of x from N and adjusts c; A unchanged. Setting x = y + c for parameters x, y: the column of x is added to the column of y in N (so the number of nonconstant terms of an equation does not increase), A unchanged. Rerouting an auxiliary v with an equation v = U + c_0 (U a parameter, an auxiliary variable, or 0): replacing v by U + c_0 in another equation is adding the row of v's equation to that row, an elementary row operation on (A | N | c); afterwards the column of v in A has a single nonzero entry, in the row of v's equation; expanding det A along that column, the matrix obtained by deleting that row and column is invertible; this is the new A. Deleting an auxiliary variable occurring in a single equation together with that equation: same determinant expansion. (AR) and (QR) are treated in E3.

**E2.2 (Lemma 2.3 of MS).** If a > d then the output is not an affine function of the parameters, and not a literal of an AND-type gate whose two inputs are unpaired parameters.
Proof. A constant output contradicts E2.1 (a >= d). If the output is a nonconstant affine function of u, pick a parameter x with nonzero coefficient. If x is paired with partner y, first fix y to 0 by (PF): a is unchanged and x becomes unpaired. Then impose on x, by (UF), the affine condition that makes the output constant (solve the output's affine expression for x). This restriction has a' >= a - 1 >= d and constant output, contradicting E2.1; no circuit implementation of this general affine restriction is needed, because the contradiction uses only the map Phi. If the output is a literal of an AND-type gate (x+al)(y+be)+ga on unpaired parameters x != y, fix y = be by (UF): the gate and the output become constant while a' = a - 1 >= d, contradiction.

## E3. Deletions and reparametrisations with their accounting

Every operation below keeps the main invariant and the two structural invariants, and we record Delta m, Delta q, Delta a, Delta s, Delta W. "No unpaired parameter increases its weight" holds whenever every rerouting is to a constant; rerouting to a literal of a parameter z raises wt(z) only if z was unpaired and isolated (6 -> 7) — an unused parameter is nobody's input and cannot gain a child, and an unpaired parameter of degree >= 2 already has the maximum weight 7.

**D1: a gate that depends on at most one input.** Let J be a gate of the acyclic part whose value is a constant or a literal of one of its inputs: this holds for constant and unary gates, gates with a constant input, gates reading the same value twice, and AND-type gates whose two inputs are parameters or auxiliary variables with linearly dependent linear parts (as affine functions of u: then one input is a constant or equals the other plus a constant, and (t+al)(t+al+c')+ga = (c'+1)(t+al)+ga is a literal of t or a constant). Reroute J and delete it. Delta m = Delta q = Delta a = 0, Delta s = -1. An unpaired parameter raises its weight (6 -> 7) only if it was isolated with J as its only child and J is rerouted to a literal of it. So Delta W <= -2 + 1 = -1, and Delta W <= -2 if J is rerouted to a constant.

**D2: an unused gate.** A gate with no children that is not the output is deleted. Delta s = -1, Delta W <= -2, Delta m = Delta q = Delta a = 0.

**D3: an equation with at most two nonconstant terms.** Such an equation E contains an auxiliary variable (else its row of A is zero), so it reads v = U + c_0 with U a parameter, an auxiliary variable, or 0. Reroute v (substitute in all equations and gates) and delete v and E. Delta s = -1, Delta m = Delta q = Delta a = 0; as in D1, Delta W <= -1, and Delta W <= -2 if U = 0 or if no unpaired isolated parameter is a parent of E.

**D4: unit parameter deletion.** Let x be unpaired and isolated with its unique child an equation E. The column N_x has a single nonzero entry (row E), so t := A^{-1} N_x != 0; choose an auxiliary variable Q with t_Q = 1, i.e. Q = x + phi(u_{-x}) for an affine phi. Apply (AR) by *exchanging roles*: in the affine system, swap the column of x in N with the column of Q in A; rename Q as the new parameter w and regard x as an auxiliary variable; substitute x <- w + phi(u_{-x}) in Phi only. No equation and no gate changes, so every parameter other than x, w keeps its children. The new matrix is A' = A B where B is the identity with its Q-column replaced by t; det B = t_Q = 1, so A' is invertible. Now the auxiliary variable x occurs only in E; delete x and E. Delta m = Delta q = Delta a = 0 (w replaces x), Delta s = -1. The children of w are among those Q had, so wt(w) <= 7, while x (weight 6) is gone and no other weight rises: Delta W <= -2 - 6 + 7 = -1.

**AR as used in E5.** Let Q be an auxiliary variable depending on an unpaired parameter x (Q = x + phi(u_{-x})). Then x occurs in some equation (else N_x = 0 and A^{-1}N_x = 0). Exchange x and Q exactly as in D4 (no deletion). Delta m = Delta s = Delta q = Delta a = 0 and Delta W = wt'(w) - wt(x), where deg'(w) = deg(Q) >= 1 (Q's column of A is nonzero, so Q occurs in an equation). In E5 we apply this only when deg(x) >= 2 and Q is also read by a gate, so deg'(w) >= 2 and Delta W = 7 - 7 = 0.

**QR as used in E6 (Case 10).** Let x, y, z be distinct unpaired parameters, G = (x+al)(y+be)+ga an AND-type gate whose only child is the XOR-type gate D = G + z + c, and let z be isolated (D its only child). Apply (QR): z <- w + (x+al)(y+be) + ga + c, P := P + {x,y}. Then D computes G + (w + G + c) + c = w: reroute D to w and delete it; G now has no child and is not the output (E2.2, as x, y are unpaired), delete it by D2. z occurred only in D, so no equation and no other gate is affected. Delta m = 0, Delta q = 1, Delta a = -1, Delta s = -2. W: -4 (two gates) + 3 (new pair) - wt(x) - wt(y) (now paired) - 6 (z gone) + wt(w) <= -4 + 3 - wt(x) - wt(y) + 1; no other parameter gains a child (D is rerouted to the fresh w; G is deleted without rerouting). With deg(x), deg(y) >= 2: Delta W <= -14.

**Moving affine gates into the affine system.** If a gate J has an affine operation b_1 t_1 + b_2 t_2 + c and both inputs are constants, parameters or auxiliary variables, replace J by the equation J + b_1 t_1 + b_2 t_2 = c with J a new auxiliary variable: at most three nonconstant terms; the new A' = (A 0; * 1) is invertible; the value of J is unchanged; s unchanged; no parameter gains a child (the parents of the equation are among the inputs of J). Delta W <= 0 (a parent may lose a child if b_1 = 0 or b_2 = 0). Done in topological order, this moves every affine gate without AND-type ancestor into the system.

**Termination.** Each of D1–D4 and QR decreases s and keeps m; each of UF/PF decreases m; nothing increases s. So every iteration of E4–E6 strictly decreases m + s.

## E4. Preliminary reductions (Cases 1–6)

Throughout E4–E6 assume a > d. Each iteration first moves all affine gates without AND-type ancestor into the system, then applies the **first applicable** case below; cases are checked in order, so each case may assume the earlier ones do not apply.

**Case 1: a deletion applies.** Apply D1–D4 repeatedly until none applies. Each has Delta a = 0, Delta W <= -1 <= 14 Delta a. Afterwards: every gate is XOR-type or AND-type with two distinct non-constant inputs; an AND-type gate on two parameters/auxiliaries has inputs with independent linear parts; every non-output gate has a child; every equation has exactly three nonconstant terms; no unpaired isolated parameter occurs in the affine system.

**Case 2: an AND-type gate G on parameters z, w with z unpaired and isolated.** Fix w to the constant making G constant; delete G by D1 (rerouted to a constant); z becomes unused. If w is unpaired (UF): wt(w) >= 6 since G is a child of w; Delta m = -1, Delta q = 0, Delta a = -1, Delta s = -1, Delta W <= -6 - 6 - 2 = -14 = 14 Delta a. If w is paired with partner r (PF): r becomes unpaired with weight <= 7; Delta m = -1, Delta q = -1, Delta a = 0, Delta s = -1, Delta W <= -3 - 6 - 2 + 7 = -4 <= 0. No other weight rises (G rerouted to a constant).

**Consequence (C) of Cases 1–2 not applying.** Let z be unpaired and isolated. z is not the output (E2.2). z does not occur in the affine system (D4 inapplicable), so its unique child is a gate G of the acyclic part. The other input of G is not a parameter: if it were and G were XOR-type (both inputs parameters, no AND ancestor) G would have been moved into the system; if AND-type, Case 2 would apply; if G read z twice or were degenerate, D1 would apply. Hence: **no gate or equation has both an unpaired isolated parameter and another parameter among its parents.** In particular, if J is a child of some parameter x and J is rerouted to a literal of one of its other parents, no unpaired parameter raises its weight.

**Case 3: a paired parameter p (partner r) has deg(p) = 0 or deg(p) >= 2.** If deg(p) = 0: fix r to 0 (PF); r is removed, p becomes unpaired and unused (weight 0), nothing is deleted. Delta m = -1, Delta q = -1, Delta a = 0, Delta s = 0, Delta W = -3 <= 0. If deg(p) >= 2: fix p to 0 (PF) and delete two of its children: each child is a gate with a constant input (D1) or an equation reduced to two nonconstant terms (D3); by (C) neither deletion raises the weight of an initially unpaired parameter (each child has the parameter p as a parent). The newly unpaired r has weight <= 7. Delta m = -1, Delta q = -1, Delta a = 0, Delta s = -2, Delta W <= -3 - 4 + 7 = 0 <= 14 Delta a. (Both deletions remain available after the first: a constant input stays constant and a two-term equation stays deletable or a gate child stays unary after any rerouting.)
After Case 3 is inapplicable, every paired parameter is isolated.

**Case 4: partners p, r have a common child H.** H is an equation v + p + r = c (three terms, one auxiliary) or a gate on inputs p, r. Impose p = r + c' (PF) with c' chosen so that H becomes constant: any c' for an equation (v = c + c') or XOR-type gate; c' = al + be + 1 for (p+al)(r+be)+ga, since then (r+be+1)(r+be) = 0. Delete H (D3 or D1), rerouting to a constant. r becomes unpaired and unused (H was its only child). Delta m = -1, Delta q = -1, Delta a = 0, Delta s = -1, Delta W <= -3 - 2 = -5.

**Case 5: a paired parameter p occurs in the affine system.** Let r be its partner. p is isolated (Case 3) with unique child an equation H_p; r is isolated with unique child H_r != H_p (Case 4). Fix r to 0 (PF) and delete H_r (D1 if a gate, D3 if an equation); by (C) no initially unpaired parameter raises its weight. p becomes unpaired and isolated (child H_p, an equation), weight 6. So far Delta W <= -3 - 2 + 6 = 1. Now apply D4 to p and H_p: Delta W <= -1. Total: Delta m = -1, Delta q = -1, Delta a = 0, Delta s = -2, Delta W <= 0.

**Case 6: an AND-type gate G on parameters p, w with p paired (partner r).** G is p's unique child (Case 3); r is isolated with unique child H_r, which is a gate (Case 5) with H_r != G (Case 4); w != r (Case 4), w != p (D1), and w is not unpaired isolated (Case 2), so w is unpaired with deg(w) >= 2 or w is paired. Fix r to 0 (PF); fix w to the constant making G constant (UF if unpaired, PF if paired); delete G and H_r by D1 (G to a constant; H_r has the parameter r as a parent, so by (C) its deletion raises no weight of an initially unpaired parameter). p becomes unpaired and unused. If w was unpaired: Delta m = -2, Delta q = -1, Delta a = -1, Delta s = -2, Delta W <= -7 (w) - 3 (pair) - 4 = -14 = 14 Delta a. If w was paired with partner r': Delta m = -2, Delta q = -2, Delta a = 0, Delta s = -2, Delta W <= -3 - 3 - 4 + 7 (r' newly unpaired) = -3 <= 0.

After Cases 1–6: every parameter occurring in the affine system is unpaired with degree >= 2 (Case 5, D4); every AND-type gate whose inputs are two parameters has both inputs unpaired with degree >= 2 (Cases 2, 6, D1).

## E5. Restructuring the minimal AND

Assume a > d and no preliminary reduction applies. The acyclic part has a gate: otherwise the output is a constant or a literal of a parameter or auxiliary variable, an affine function of u, contradicting E2.2. Let G be the first gate in topological order; its inputs are constants, parameters or auxiliary variables; it is not affine (such gates were moved) and not degenerate (D1), so G is AND-type with two inputs that are parameters or auxiliary variables with independent linear parts. Call G the minimal AND.

**Making both inputs parameters.** If an input of G is an auxiliary variable Q, its linear part is nonzero, so Q depends on some parameter x; x occurs in the affine system (else N_x = 0), hence x is unpaired with deg(x) >= 2. Apply AR exchanging Q and x: Delta W = 0 as deg'(w) >= 2 (w = former Q is in an equation and read by G). Then re-run the moving of affine gates and Cases 1–6; if a case applies, perform it and end the iteration. Otherwise, if the other input of G is still an auxiliary variable, repeat (an invertible affine change of parameters preserves the linear independence of the two inputs, so the second auxiliary depends on a parameter other than w). After at most two exchanges both inputs of G are parameters x, y; by Cases 2 and 6 they are unpaired with deg(x), deg(y) >= 2.

**No child of G reads x or y.** If a child J of G also reads x, then J is a gate computing h(x, G(x,y)) for some h in B2; relabel J with the operation (x, y) -> h(x, G(x, y)) and reroute its inputs to x and y. The function computed is unchanged; J stops being a child of G, stays a child of x, and y gains at most one child (deg(y) >= 2 already, weight stays 7). Delta m = Delta s = Delta q = Delta a = 0, Delta W <= 0. Same with x, y swapped. After each such rerouting, move affine gates and check Cases 1–6, ending the iteration if one applies. Each rerouting removes a child of G and none creates one, so this terminates. If no case applied, no child of G reads x or y; G is not the output (E2.2) so it has k >= 1 children (D2 inapplicable).

## E6. Eliminating the minimal AND (Cases 7–10)

Swap names so that deg(x) >= deg(y) >= 2; k >= 1 is the number of children of G.

**Case 7: deg(x) = deg(y) = 2 and x, y have the same second child B != G.** If B is an equation it has three nonconstant terms, one an auxiliary variable, so B is v + x + y = c; put h(x,y) := x + y. If B is a gate, its inputs are x, y; let h be its operation. The AND-type G takes the same value on three points of F_2^2; among these three points, two have the same value of h. These two points form a line {al x + be y = ga} ((al, be) != (0,0)), on which both G and h are constant. Restrict to the line by one (UF): x = ga if be = 0, y = ga if al = 0, x = y + ga if al = be = 1. (If B is the equation, h = x + y forces al = be = 1, and B becomes v = c + ga.) Then G is constant and B is constant (gate) or v = const (equation); delete G by D1 and B by D1/D3, rerouting to constants. One of x, y is removed by the restriction and the other becomes unused (all their occurrences were G and B). Delta m = -1, Delta q = 0, Delta a = -1, Delta s = -2, Delta W <= -7 - 7 - 4 = -18 <= -14.

Henceforth Case 7 does not apply: if deg(x) = deg(y) = 2, the second children B_x of x and B_y of y are distinct.

**Bottleneck configuration:** deg(x) = deg(y) = 2, k = 1, and the unique child D of G has as its other input an unpaired isolated parameter z. (D is XOR-type or AND-type by Case 1; D != B_x, B_y since D's parents are G and z.) Before Case 8, check for this configuration and if present apply Case 9 or 10.

**Case 8: not the bottleneck configuration.** Let k_1 be the number of children of G whose other parent is an unpaired isolated parameter (0 <= k_1 <= k). Fix x (UF) to the constant making G constant. Delete, by D1/D3, all deg(x) children of x (G first, rerouted to a constant, then the others) and then all k children of G (now gates with a constant input, D1). These deg(x) + k deletions are distinct (no child of G reads x). Weight bookkeeping: x loses 7. Each deletion contributes -2. Which unpaired parameters can gain weight? Only an initially isolated z whose unique child is deleted and rerouted to a literal of z. By (C), the unique child of z is not a child of x (it would have the two parameters z, x as parents), so it is one of the k_1 children of G with an isolated other parent. Hence at most k_1 weights rise, by 1 each. Delta m = -1, Delta q = 0, Delta a = -1, Delta s = -(deg(x) + k),
    Delta W <= -7 - 2 (deg(x) + k) + k_1.
If deg(x) = 2 then deg(y) = 2, y's children are G and B_y, y is not a parent of B_x (B_x != B_y) nor of any child of G; G is rerouted to a constant, B_x and the children of G are rerouted to literals of their other parents, none of which is y; so y gains no child and loses G: deg(y) becomes 1 and wt(y) drops 7 -> 6, an extra -1. Therefore
 - deg(x) >= 3: Delta W <= -7 - 2 deg(x) - 2k + k_1 <= -13 - k <= -14;
 - deg(x) = 2, k >= 2: Delta W <= -7 - 4 - 2k + k_1 - 1 <= -12 - k <= -14;
 - deg(x) = 2, k = 1: Delta W <= -7 - 4 - 2 + k_1 - 1 = -14 + k_1, and k_1 = 0 here (k_1 = 1 would be the bottleneck configuration), so Delta W <= -14.
In all subcases Delta W <= -14 = 14 Delta a.

**Case 9: bottleneck, D AND-type.** D = (G + de)(z + et) + th. Choose x_0, y_0 with G(x_0, y_0) = de (G is nonconstant). Fix x = x_0 and y = y_0 (two UF). G becomes the constant de and D the constant th; delete G, D by D1 (to constants), and delete B_x, B_y (D1 if gates with a now-constant input, D3 if equations). The four are distinct (B_x != B_y; D != B_x, B_y). z becomes unused (D was its only child). No initially unpaired parameter other than x, y, z increases its weight (some may decrease, which only helps): G, D go to constants; B_x has parent x and B_y has parent y, so by (C) their rerouting raises nothing. Delta m = -2, Delta q = 0, Delta a = -2, Delta s = -4, Delta W <= -7 - 7 - 6 - 8 = -28 = 14 Delta a.

**Case 10: bottleneck, D XOR-type.** D = G + z + c with x, y, z distinct unpaired parameters, G's only child D, z's only child D, deg(x) = deg(y) = 2. Apply QR as in E3: Delta a = -1, Delta W <= -14 = 14 Delta a.

## E7. The main lemma and Theorem E

**E7.1 (Lemma 4.2 of MS).** If a > d, one iteration (preparatory operations plus the first applicable case) yields a state with m + s strictly smaller, Delta a in {0, -1, -2} and Delta W <= 14 Delta a.
Proof. The preparatory operations (moving affine gates, AR exchanges in E5, reroutings in E5) have Delta m = Delta s = Delta a = 0 and Delta W <= 0. Each case has Delta a in {0, -1, -2} and Delta W <= 14 Delta a as computed (Cases 1, 3, 4, 5, the paired subcases of 2 and 6: Delta a = 0, Delta W <= 0; Cases 2 (unpaired), 6 (unpaired), 7, 8, 10: Delta a = -1, Delta W <= -14; Case 9: Delta a = -2, Delta W <= -28). Every case decreases m + s (E3, Termination). Every case is well defined because a > d was used only through E2.1/E2.2, which hold at the start of the iteration; the case analysis is exhaustive: if Cases 1–6 fail, E5 produces the minimal AND with parameter inputs x, y as described, and then exactly one of Case 7, the bottleneck configuration (Case 9 or 10 according to the type of D), or Case 8 applies.

**Proof of Theorem E.** Let C be a pinned circuit computing f, with |C| gates. Start from the initial state (E2): m = a = n, q = 0, s = |C|, every parameter unpaired with weight <= 7, so W_0 <= 2|C| + 7n. While a > d apply E7.1. Since m + s strictly decreases and stays >= 0, the process stops after finitely many iterations with a_T <= d (initially a = n > d). Summing Delta W <= 14 Delta a over the iterations: W_T - W_0 <= 14 (a_T - n). With W_T >= 0 and a_T <= d:
    2|C| + 7n >= W_0 >= 14 (n - a_T) >= 14 (n - d),
so |C| >= 3.5 n - 7 d. QED.

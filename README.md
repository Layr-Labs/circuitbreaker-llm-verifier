# CircuitBreaker bounded review pilot
A private bounded pilot package generated by the generic llm-verifier
authoring workflow. It ranks proved exact rational gate coefficients for fixed total
NP families in the full B2 model. The published 31/10 result is seed data only.

This pilot binds the complete theorem and proof through typed canonical inputs limited
to 16 KiB total, with each string at most 4096 characters and each rational integer at
most 256 digits. It cannot yet accommodate long new research proofs. Never truncate
proofs or move them out of the binding silently. See docs/transport.md for limits and
docs/baseline.md with docs/sources.json for seed provenance.

Provisional LLM review and public simulations are not official mathematical approval.
Public cases marked synthetic are protocol tests, never discoveries. The mathematical
superlinear endpoint is represented in the dossier; current platform scores remain
finite-only. This is not an unrestricted research launch. Human review is required
before any official frontier or endpoint promotion.

Future generic work: a protected attachment-digest/input-binding mechanism could bind
long immutable proof bundles without copying all proof bytes into tool inputs. It
requires an explicit contract and independent review; it is not implemented here.

Use generated AUTHORING.md and context command for the exact edit map and checks.
The generated context command identifies the task's read/inspect/edit files. Use the
pinned generic CLI's `check --root . --definition <external-definition.json>
--receipt <external-receipt.json>` for inventory and scripted conformance, and the
provided protected-checker workflow for credential-free Docker known-answer cases.
These local checks do not call a model or qualify scientific validity.

Output follows llm-verifier's judgment contract: valid plus a finite score tuple or
scores:null, with exact bound records retained in the dossier. The main-claim checker
uses typed inputs; lp-certificate is optional arithmetic support. Only explicit exact
main-claim ID acceptance permits numeric projection. Partial lemmas remain unscored.
Credentials, hidden qualification and live-run receipts are kept outside this export.
